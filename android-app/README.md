# Webly Norge Android app

Simple native Android wrapper for https://weblynorge.no with native navigation.

- Package: `no.weblynorge.app`
- Version: 1.0.0 (1)
- minSdk: 23
- targetSdk: 36
- compileSdk: 36

Google Play requires an Android App Bundle (AAB) for new apps. The GitHub Actions workflow builds a debug APK for testing and an unsigned release AAB. Sign the AAB with your permanent upload key before uploading it to Play Console.
